# API Integration Fundamentals Assignment

Simple Node.js/Express project demonstrating REST API integration.

## Concepts demonstrated
- REST API
- HTTP GET requests
- JSON data
- API integration using fetch
- Error handling
- Basic frontend API consumption
- Mocha + Chai + Supertest testing

## Run
```bash
npm install
npm start
```

Open:
http://localhost:3000

## Test
```bash
npm test
```

## Integrated API
JSONPlaceholder is used as a simple public REST API for demonstration:
https://jsonplaceholder.typicode.com/
